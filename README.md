# ระบบคิวรับบริการงานทะเบียน

## Team Charter
นาย ธราเทพ สีทอง Developer B มีหน้าที่ทำ Database อยากเรียนรู้การออกแบบฐานข้อมูล การทดสอบ API ด้วย Postman และการใช้ GitHub ทำงานร่วมกันเป็นทีม

### เป้าหมายของโครงงาน
พัฒนาระบบจองคิวรับบริการงานทะเบียน
เพื่อให้นักศึกษาสะดวกในการขอเอกสาร

### ข้อตกลงการทำงาน
- แบ่งหน้าที่ให้ชัดเจน
- ช่วยกันตรวจสอบและทดสอบระบบ
- บันทึกการเปลี่ยนแปลงโค้ดผ่าน GitHub
