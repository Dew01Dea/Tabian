# ระบบคิวรับบริการงานทะเบียน

## Team Charter

### เป้าหมายของโครงงาน
พัฒนาระบบจองคิวรับบริการงานทะเบียน
เพื่อให้นักศึกษาสะดวกในการขอเอกสาร

### ข้อตกลงการทำงาน
- แบ่งหน้าที่ให้ชัดเจน
- ช่วยกันตรวจสอบและทดสอบระบบ
- บันทึกการเปลี่ยนแปลงโค้ดผ่าน GitHub

## สมาชิกทีมและสิ่งที่อยากเรียนรู้
1. นายดุรงค์กร สุวรรณประเสริฐ · Developer A (API/Server) · อยากเรียนรู้การพัฒนา API การรับส่งข้อมูลระหว่าง Frontend และ Backend และการจัดการข้อผิดพลาดของระบบ
2. นายธราเทพ สีทอง · Developer B (Database/Testing/Documentation) · อยากเรียนรู้การออกแบบฐานข้อมูล การทดสอบ API ด้วย Postman และการใช้ GitHub ทำงานร่วมกันเป็นทีม
